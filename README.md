# 五瓶智能分药与取药提醒系统 · 结构概念演示页

按 Grok 提示词 **v5（圆桶、五药瓶、五组瓶底三层叠片接口、公共汇流漏斗）** 实现的单文件 3D 交互演示网页，用于大学生比赛的结构讲解与屏幕录制。

页面常驻标识：**结构概念 · 模拟数据 · 未连接实物**。所有识别、计数结果均为固定可复现的预设模拟数据；页面不含任何 AI 密钥，不伪造实时视频、实测准确率或硬件在线状态。

---

## 一、启动方法（本地静态 HTTP）

本页使用本地固定版本的 Three.js（`libs/three.module.js` + `libs/controls/OrbitControls.js`，0.170.0），**正常运行不需要联网**。首次使用前请确认 `libs/` 目录完整（本仓库已包含）。

### 方式 A：双击 `start.bat`
```bat
start.bat
```
脚本会自动用 Python 起一个本地服务器并打开浏览器（地址 `http://localhost:8765/`）。

### 方式 B：手动启动
```bash
# 在本目录下执行（任选其一）
python -m http.server 8765
py -3 -m http.server 8765
npx serve -l 8765 .
```
然后浏览器打开 http://localhost:8765/

### 网络依赖说明
- 三维库已随项目本地化（`libs/`），**加载页面本身无需外网**。
- 若 `libs/` 缺失或被删除，页面会显示「三维引擎加载失败」的错误提示并切换为 2D 备用示意，不会白屏；右侧面板仍然可见。此时可从 CDN 重新下载：
  - `https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js`
  - `https://cdn.jsdelivr.net/npm/three@0.170.0/examples/jsm/controls/OrbitControls.js`（放到 `libs/controls/`）

### 稳定性提示
- 直接双击打开 `index.html`（file:// 协议）在部分浏览器下 ES 模块加载会受限，**推荐使用上面的本地 HTTP 方式**。
- 关闭页面后，倒计时与提醒不会继续。

## 二、页面结构

- 左侧（约 65%）：三维模型区——圆桶整机、五瓶、瓶底三层接口、公共汇流漏斗、药盒、电子区、两只摄像头。
- 右侧：运行状态（目标/光电/视觉三向量）、部件信息卡、手机模拟面板（A–E 数量 0–5）、服务器与通信（Mock 适配层）、托盘视觉（CAM-01 模拟）、库存观察（INV-01）、演示场景按钮、部件与采购状态。
- 底部：流程时间线 + 事件日志（带时间与指令编号）。
- 手机端自动改为上下排列。

## 三、三维操作

- 视角：整体 / 正面 / 背面 / 左侧 / 右侧 / 俯视 / 开盖俯视；拖动旋转、滚轮缩放、复位视角、自动旋转。
- 开关：透明外壳、半剖视、部件标签、摄像头视场锥。
- **整机拆解滑杆**：圆盖→五组瓶底组件→公共漏斗→药盒 分层拉开；拆解时出药动作自动暂停，滑杆回 0 恢复。
- **单瓶接口拆解**（A–E 按钮）：对应瓶底三层叠片分层展开，其余四组半透明，旁注「同结构共 5 组」。
- 点击任意部件弹出部件卡：编号、名称、数量、作用、位置、接口、状态（拟采购/机构待验证/待核算）。
- 圆盘开孔为**真实挖孔几何**（ExtrudeGeometry 打孔），不是深色贴片；L1 与 L3 孔位相距 180°，L2 定量腔在移动中最多对准其一，**任意中间位置不贯通**，胶囊不会穿过实心板。

## 四、演示场景（互斥，从明确初始状态运行）

主场景按钮：
1. **正常配药**：默认 A2/B1/C0/D1/E1，C 目标为 0 自动跳过；A→E 串行执行（同一时间仅一路），逐粒经漏斗、出口计数后进入药盒，核验三向量一致后等待取药。
2. **缺一粒·两路一致→有限补发**：A 第 2 粒一次释放未落粒，光电与视觉一致确认缺 1 → 每瓶每任务最多一次、每次 1 粒的补发，然后重新核验。
3. **多一粒→停止并提醒**：B 单周期记录 2 个脉冲 → 立即转异常停止，多余胶囊留在盒内等待人工处理。
4. **部分取走→不补发**：只取 1 粒显示「仍有剩余」并继续提醒；全部取走才记录「药盒已清空 / 用户确认」，不宣称已验证服药。
5. **超时未取→提醒（加速）**：真实间隔 300 秒，页面演示加速为 10 秒且全程标注；提醒不触发出药。
6. **E 瓶低库存→上报**：模拟 硬件感知→服务器→手机 上报链，「E 瓶已补充」按钮解除告警。

折叠区（附加故障）：计数与视觉冲突（不自动补）、错颜色/低置信度、运行中抽出药盒（离位停新料、在途粒子记待人工核对、放回需确认）、连接中断（恢复后未确认任务不重放）。

其他控制：暂停/继续、下一步（步进模式）、重置（清除全部计时器与动画）、慢速动作、允许提示音、演示/实物模式切换、自动讲解、录屏布局。

## 五、自动讲解与录屏

- 「自动讲解」按钮：约 2 分钟完整脚本（外观→开盖→单瓶三层→一个机械周期→装配→链路→正常流程→补发→多粒停止→部分取走与提醒→E 低库存→总结），支持「暂停/继续」「下一步」「重播」（重播=再次点击）。
- 「录屏布局」复选框：隐藏开发设置，保留模型、动作字幕、关键计数与「模拟演示」标识。
- 录制方法：进入录屏布局后用系统录屏工具（Windows：Win+G / Win+Alt+R）录制浏览器窗口即可。**本页不输出 MP4 文件**。

## 六、模拟与实物的边界

- **本页可用（模拟）**：三维结构、拆解与标签、三层接口暂定原理动画（标注待验证）、串行出药流程、公共出口光电计数、模拟视觉核验、有限补发策略、300 秒提醒（演示加速）、库存分级上报、日志与时间线。
- **需要接 AI 才能做**：真实胶囊颜色/类别识别与数量清点（当前为预设数据）；真实毫米级尺寸识别需参照物或相机标定。本页无模型密钥、无在线推理。
- **需要实体硬件才能做**：五路接口真实动作、光电真实计数、SW-01 在位检测、摄像头、ESP32-S3 通信、Wi-Fi 链路。切到「实物模式」时页面显示**未连接**；设备未回报前，网页动画不作为执行成功依据。
- 通信适配层独立（Mock 默认）；真实接口接入前不得伪造设备确认。

## 九、符合老师要求的关键对应

| 老师要求 | 本页实现 |
| --- | --- |
| 5 个药瓶，每瓶三层接口 | 桶内 A–E 五瓶，各自一组 L1/L2/L3 叠片（共 5 组，机构待验证） |

| 视觉核验、缺补多停 | CAM-01 模拟视觉按类别+数量核验；缺 1 一致才补 1 次；多粒/冲突停止人工处理 |
| 每 5 分钟提醒 | 真实 300 秒，演示加速 10 秒并全程标注 |
